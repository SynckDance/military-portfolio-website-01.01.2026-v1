MOD-003 // SOFT ROBOTICS

THE SENSORIUM PROJECT

● PHASE 02

OVERVIEW

Exploring soft robotics, fluidic/haptic sensing in dance performance through the "Me Duniya" piece. The ACCS (Affective Choreographic Control System) translates touch intensity into real-time visual and spatial transformations.

ACCS SYSTEM

HARDWARE LAYER

Soft fluidic pressure sensors, micro-vibration elements, wearable rings

SIGNAL PROCESSING

Intensity, stability, fluctuation feature extraction

AFFECTIVE OUTPUT

Light, projections, spatial audio manipulation

MOD-004 // ARCHIVAL INTELLIGENCE

THE THINKING ARCHIVE

● ACTIVE

OVERVIEW

Transforming frozen dance archives into dynamic, AI-augmented entities capable of ethical reasoning with embodied data. The framework proposes Motion Archive, Living Archive, and Thinking Archive models as alternatives to static preservation.

ARCHIVE MODELS

MOTION ARCHIVE

Static preservation of movement data

LIVING ARCHIVE

Dynamic, evolving collections with community input

THINKING ARCHIVE

AI-augmented ethical reasoning with embodied data
